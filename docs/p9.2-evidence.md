## Delivered

Four `demo-v1` topics (Arrays, Iteration, HTML, CSS), two per domain, with 60 original practice questions: five checkpoint and ten test-out items per topic. Seed validation rejects draft/mismatched banks, cycles, missing prerequisites, invalid options/keys and incorrect counts. Reading and assessment catalogs must agree. Content/key review is explicitly recorded as Codex review, not human certification.

Fresh PostgreSQL schema v2 stores private question banks, frozen attempts, request IDs, answers, immutable results, permanent first completions, scoped resource cache and durable completion facts. Checkpoints require 3/5; test-outs require 8/10, once before any assessment of a topic/version. Passing unlocks dependent topics. Theta is a disclosed [-3,3] practice heuristic. Reset cancels active attempts and clears current progress while retaining results and award uniqueness. No client score or theta is accepted.

The shared-shell UI includes topic preview, graph/list, resources, saved quiz/resume/history, final answer review and pending/confirmed Core receipts. All new styling uses shared theme tokens. No optional 3D dependency was introduced. Resource lookup defaults to approved seed links; optional bounded Wikipedia lookup is cached and isolated by Hub/node. No Gemini, YouTube or paid provider is required.
