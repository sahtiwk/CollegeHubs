# P8.1 — independent Interview and private PDF resumes

Local acceptance completed 2026-10-07. P8.2 generation/evaluation/rewards is not started. Hosted release remains P11-gated.

## Delivered

The independent Interview workspace adapts the supplied AI-Interviewer Resume/Interview/Session models, resume controller/upload middleware and candidate resume workflow. Own Mongo connection/readiness and A3 handoff replace local User/auth authority. Core public credentials are exchanged only server-to-server; browser identity uses scoped opaque cookies, exact Origin and CSRF. No sibling runtime/database imports are added. Local User/admin/jobs/seed/socket/Redis/Adzuna/OpenAI/RAG/Cloudinary dependencies have no active caller or required key.

Multer memory storage accepts only one PDF file up to 5 MiB, no extra form fields. MIME/extension/signature/size validation precedes maintained PDF.js text extraction in a bounded worker. Eight-second parse timeout, cancellation, V8 heap limits, 20-page/8,000-character bounds, one admitted upload/parser, attempt/retained-record limits and explicit failure codes constrain the flow. No original bytes, cloud object/public ID, download URL or AI parser are retained. `storageDriver=none`, `fileUrl=null` are explicit. Only owned detail reads expose private extracted text; lists remain metadata only.

Draft attachment is scoped by both Core subject and Hub. Transactional attachment/deletion serialize on the resume reference fence; deleted text is physically removed and draft references become unavailable. Session/report schema rejects copied resume text, and deletion preserves seeded completed report rows. Those rows are **test fixtures**, not completed AI sessions. P8.2 must load a live owned resume before generation.

Source `ResumesPage.jsx` upload/card/expanded-details/delete-confirmation flow is adapted into a lazy shared web feature. It uses the existing auth coordinator, router, theme tokens, shell and error boundary. No duplicate provider/store/navbar/toast/global stylesheet is added. Default-resume/AI-reparse/cloud-download controls are removed. The UI accurately explains privacy, limits, truncation, unsupported scans/encryption and upcoming practice availability.

The shared gateway streams a large body only for exact POST `/api/interview/resumes/upload`, bounded at file cap plus 64 KiB multipart overhead. Other routes retain the 64 KiB request cap and existing credential filtering/JSON response rules. Integration exposed a cancelled-stream socket reset and a Node Readable-to-Web adapter close race. The final Vite adapter uses a bounded stream and drains cancellation without destroying the browser socket; oversized uploads now return 413 through the real gateway.
