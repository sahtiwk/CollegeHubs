# P9.1 — scoped Learn API and learner pages

Date: 2026-10-07. **Implementation delivered; automated/API acceptance PASS. Browser acceptance pending.** Hosted release remains P11-gated. P9.2 is not started. This phase does not claim quiz/grading/mastery-event completion.

## Delivered scope

- Separate Learn PostgreSQL schema v1 with scoped learners, paths, nodes, prerequisite edges, content, enrollments, node states and module sessions. Composite foreign keys enforce Hub/domain consistency. One learner per Core subject/Hub and one state per learner/node. No Core DB imports, guessed Clerk mappings, vector extension or local Aura/streak authority.
- Explicit current-schema bootstrap into a **fresh, named, allowlisted disposable** database. Production, unconfirmed, non-allowlisted and populated targets are refused. No historical migration snapshot or data reset is run.
- Retained dashboard/domain/stats/milestones, onboarding/intake/init-graph, node, recommendation, fast tutor and preferences/reset controllers under `/api/learn`. Exact session/Origin/CSRF, bounded fields, closed body schemas and parameterized scoped SQL. Retired maintenance/generation/slow-tutor and future grading endpoints return404.
- Idempotent enrollment and learner-row transactions preserve progress on repeated init; only roots start unlocked. Self-rating is separate from assessed theta. Reset changes only the owner's current path and never changes Core receipts/balances/award uniqueness.
- Shared-shell React pages for learning dashboard, onboarding, topic reading and preferences; module session expiry/reconnect, abort/stale-result protection, accessible roadmap/list and explicit reset confirmation. CSS uses shared Hub tokens and existing fonts. This is source/build verification of those UI behaviors, **not a claim of a completed browser walkthrough**.
- Attributed `reading-v1` starter catalog for DSA/Web: two nodes per domain, one root and one dependent topic. Seeded MDN reading links and template guidance need no Gemini/YouTube key. The reviewed question bank and assessment progression are P9.2 work.

Full payloads, source adaptation inventory, bootstrap instructions and safe-stop behavior: [Learn operation](learn.md). Source/reading notices: [THIRD_PARTY.md](THIRD_PARTY.md).
