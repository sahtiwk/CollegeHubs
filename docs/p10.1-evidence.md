# P10.1 implementation evidence — 2026-10-11

Implemented and locally verified following the user's explicit request to activate the optional phase. No local implementation blocker remains. Hosted activation still requires the P10.2 read credentials and rollout of both phase commits; this document does not claim hosted deployment.

## Delivered

- Learn returns at most five latest assessed topics below 0.6 within 30 days, scoped to the current user, Hub, version and active enrollment. Unassessed/reset, stale, foreign and superseded failing results are excluded.
- Separate signed read scope, bounded transport and the shared two-request optional-read budget. Core accepts only IDs revalidated against a fresh owned response.
- A distinct recommendation kind in ModuleGrant, partial unique reference index, owner/Hub/Interview binding, 60-second expiry and atomic one-use consumption. Existing session grants and their indexes remain compatible.
- Interview imports through its server credential and current session JTI even when a session already exists. Draft leases exclude concurrent generation/import; generated questions cannot be retargeted.
- Optional picker in the saved setup, explicit selection, simple-heuristic disclosure, and Groq topic-label disclosure. Saved labels/versions reach the real generation prompt's delimited untrusted JSON block. No Aura/streak mutation.
